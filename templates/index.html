📋 工具使用步骤
  1. 「数据库配置」 填写源/目标库连接信息，测试连接。
  2. 「表管理」 选择表，点击「生成映射」自动对比 R1/V5 字段，V5 独有字段补默认值。
  3. 设置时间范围（默认迁移 2026 年之前数据），点击「启动」开始迁移。
  4. 「迁移进度」 查看实时进度、可暂停/恢复。
  5. 断点重试： 按主键分批迁移，自动记录 last_pk；中断后再次启动会继续迁移剩余数据。
  6. 「迁移日志」 查看每个批次详情（主键范围、耗时、错误信息）。

🧱 R1 → V5 字段差异要点
  • 整数列：int(1)/int(4)/tinyint → int(11)，兼容。
  • decimal(16,1) → decimal(16,2)，迁移时由 SQL CAST 处理。
  • 字符串长度变化（varchar(36)→varchar(72)、512→2048）：兼容。
  • 源表 hour_to_day、carbon_copy_staff_id、original_data、show_unit 等字段目标库不存在，跳过。
  • 目标独有字段（code、status、vouchdate、inner_leave_type_id 等）按默认配置补默认值。
⚠️ 注意事项
  • 首次运行必须先在「表管理」生成字段映射。
  • 目标库已存在数据时，遇到主键重复会跳过重复行。
  • 迁移按 id ASC 顺序 + 时间范围筛选，断点重试安全。
  • 建议先备份或在测试环境验证。
  • 运行 stop 后当前批次完成后即停止（断点已保存）。
